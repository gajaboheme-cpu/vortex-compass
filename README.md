# Vortex Compass

A Next.js/TypeScript quiz with no database, email delivery, or dynamic PDF generation. One small server route (`/api/reading`) reads the optional story box.

## Local setup

1. Run `npm install`.
2. Copy `.env.example` to `.env.local` and add the GoHighLevel webhook and experiences URLs.
3. Run `npm run dev`.

When the webhook is not configured, submissions are stored under `vortexCompassResult` in browser local storage. The result screen always continues.

## How a reading works

Every result answers two things: which Alchemist (WHERE) and how far the work has moved (HOW FAR).

- Nine questions find the direction: Nourish (Restoration), Release (Liberation), Shine (Illumination), Connect (Belonging), Expand (Becoming).
- Three stage questions find the stage: Breaking Down (Nigredo), Clearing (Albedo), Seeing (Citrinitas), Living It (Rubedo). The most-picked stage wins; a tie goes to the earlier stage.
- An optional story box. If filled, `/api/reading` checks it for crisis language first, then asks Claude for a stage and one personal line. The story can move the stage one step at most. The words are never stored, logged, or sent to GoHighLevel.
- If someone writes about wanting to die or hurt themselves (or someone else), a support screen with crisis lines shows before the reading.

All twenty readings live in `app/quiz-data.ts` (`readings`). The five engravings are in `public/images/plates/`.

Webhook submissions include `primaryArchetype`, `primaryStage` (Latin), `primaryStageName` (plain), `fullReading`, `supportingArchetype`, and the answers. The story is never included. A completed result session is stored locally so refreshing shows the already-settled Compass instead of replaying its animated reveal.

## Static guides

Add the five final PDFs to `public/guides/`, then set each corresponding `guideAvailable` field in `app/quiz-data.ts` to `true`. Until then, production hides the download button and development shows a safe placeholder.

Question 9 and the result page use the plates at `public/images/plates/{nourish,release,shine,connect,expand}.webp`.

Result actions include a 1080×1350 social-image export and a browser print view for saving the personalized reading as a PDF. The static full-guide PDFs remain separate downloads and are never generated by the application.

## Deploy

Commit this directory to GitHub, import the repository into Vercel, and configure `NEXT_PUBLIC_GHL_WEBHOOK_URL`, `NEXT_PUBLIC_EXPERIENCES_URL`, `NEXT_PUBLIC_BOOKING_URL` and `ANTHROPIC_API_KEY` in the Vercel project settings. Without the API key the story box still works; it just skips the personal line.
